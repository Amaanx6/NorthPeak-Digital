## Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/northpeak-digital.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
